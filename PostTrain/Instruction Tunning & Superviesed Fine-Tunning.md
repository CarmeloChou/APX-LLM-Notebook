# Instruction Tunning & Superviesed Fine-Tunning

openAi在论文中一直使用SFT而非指令微调这个说法。

事实上，对预训练模型的指令微调，是构建一系列的对话数据，可以是垂类领域或者其他类型的对话信息，在不改变模型结构的前提下，对参数进行更新，得到微调后的对话模型。

## SFT微调

在agent当中，可以收集用户修改的指令对用来微调。比如

```bash
> 助手：已生成ppt样式...
> 用户：把ppt格式调整为卡片形式
> 助手：将ppt样式调整为卡片布局
```

对于这样一个问答对，可以将结果收集，比如这样:

```bash
输入序列 = [你的纠偏指令] + [Agent 改对的回复]
标签序列 = [-100, -100, …, -100 | 回复的 token IDs]
```

将前面的用户提示给屏蔽，梯度只落到agent操作上，只训练agent的回答操作，将个人的操作习惯蒸馏到模型中。
